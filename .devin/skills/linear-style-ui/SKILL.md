# Linear Precision + Clean Daylight

Сайт должен ощущаться лёгким и воздушным (светлая палитра чистоты по умолчанию, глубокая `.dark` — опционально)
и при этом инженерно точным, как Linear. Ниже — правила, которые проверяются на каждом PR.

## Токены и поверхности
- Цвета только через токены `globals.css` (`bg-brand`, `text-primary`, `border-border`, `bg-muted`, `text-sponsor`…).
  Никаких `zinc/white/red/sky/emerald/amber` и «сырых» hex в компонентах.
- Лайм `--brand` — только заливки (кнопки, полосы прогресса, лучи). Текстовый акцент — `text-primary` / `text-link`.
- Карточки — `.data-surface` (1px граница, внутренний блик, тонированная тень) + `rounded-panel`.
- Ключевые B2B-карточки (PRO Спонсор, виджет владельца компании, аналитика `/admin`) — добавить `.linear-beam`:
  1px градиентный луч по верхней кромке (`brand → mint`). На B2C-карточках луч не ставим — он сигнал «бизнес-слоя».
- Интерактив под курсором — `SpotlightCard` из `components/ui/fx` (радиальная подсветка + маска кромки, без ререндеров).
- Shape lock: интерактив = `rounded-full`, панели = `rounded-panel` (14px), поля и мелочь = `rounded-control` (10px).
- Новые глобальные правила — только внутри `@layer base` / `@layer components`, иначе они перебьют утилиты.

## Типографика
- `Geist Sans` (`font-sans` / `font-display`) для текста, `Geist Mono` через утилиту `font-data` для чисел:
  цены, индексы доверия, pH, проценты, номера шагов, счётчики. Всегда `tabular-nums`.
- Подсказки клавиш — `<kbd>` в стиле Linear: `font-data text-[11px] rounded-[6px] border border-border bg-muted/70 px-1.5`.
- B2C-чек-листы и предупреждения: минимум `text-[15px] leading-7` для шагов, `text-sm` для подсказок.
  Капс и `text-[10px]` в пользовательских инструкциях запрещены.

## Движение
- Только `motion/react` (уже в зависимостях) — без сторонних анимационных библиотек.
- Пружины: `{ type: "spring", stiffness: 260–420, damping: 22–34 }`; длительности переходов ≤ 300 мс.
- Всегда уважать `useReducedMotion()` (и `MotionProvider reducedMotion="user"`): итоговое состояние сразу в разметке для SSR.
- Микро-фишки: хоткей `/` и `⌘K`/`Ctrl+K` для поиска, «лазерная шторка» в `BeforeAfter`, микро-триумф в `DiyChecklist`.
  Новые фишки — тактильные и мгновенные, без блокирующих модалок.

## Запреты
- Тяжёлые многослойные тени, кислотные/радужные градиенты, неоновые свечения вне фокуса.
- Мелкий нечитаемый текст в B2C (меньше `text-xs` для значимой информации).
- Более одного рекламного блока на экран; реклама без видимой маркировки «Реклама»/«Спонсор».
- Декоративные анимации, которые нельзя выключить через reduced motion.

## Чек-лист перед коммитом
1. Цвета — токены; числа — `font-data`; карточки — `data-surface`.
2. Клавиатура: фокус видим (`focus-visible:ring-*`), тап-цели ≥ 44px на мобильных.
3. `npm run typecheck && npm run lint && npm run test`.
