# Клининг Рейтинг — прототип

Геймифицированная экосистема для рынка клининговых услуг: премиальный светлый B2C-хаб с рейтингом компаний и спонсорскими интеграциями + тёмная B2B-«Арена», где компании в реальном времени поднимают свою позицию ставками.

## Технологии
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (кастомные light/dark токены — см. `app/globals.css`)
- Framer Motion (анимации, FLIP-переходы, сигнатурный переход между темами)
- Zustand (стор аукциона и стор перехода между темами)
- Recharts (спарклайны истории ставок)
- canvas-confetti (эффект при покупке буста)

## Запуск
```bash
npm install
npm run dev
```
Открыть http://localhost:3000

## Страницы прототипа
- `/` — B2C-хаб: поиск, категории со спонсорскими бейджами, топ компаний, трастовая полоса.
- `/rating` — динамический рейтинг: фильтры, сортировка, короны топ-3, прозрачная плашка «Продвигается».
- `/arena` — B2B-арена: живой лидерборд, ставки, бусты, кошелёк, таймер раунда, лента алертов.

Все данные — мок (см. `lib/mock-data.ts`), «живые» ставки конкурентов симулируются на клиенте (см. `store/auctionStore.ts`).

## Деплой
- Быстрый предпросмотр: через встроенный деплой-инструмент (Netlify-раннер, фреймворк `nextjs`).
- Целевой прод-путь: Cloudflare Pages через `@cloudflare/next-on-pages` + Wrangler, с реальным бэкендом на Cloudflare Workers + D1 (реляционные данные) + Durable Objects (комната аукциона в реальном времени) — см. план архитектуры.
